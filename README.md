# Arabic sign language detection model

This project aims to **detect Arabic sign language gestures** using **Computer Vision** and **Deep Learning** techniques.  
The model was trained with **YOLOv8 (Ultralytics)** to recognize and analyze hand signs **in real-time** through a webcam.  

---

##  Features  
-  High-accuracy detection of Arabic sign language gestures.  
-  Real-time detection using a webcam.  
-  Powered by a fine-tuned YOLOv8 model trained on a custom dataset.  
-  Can be integrated into other applications such as instant translation or educational tools for people with hearing impairments.  

---

##  Technologies Used  
- Python  
- OpenCV  
- Ultralytics YOLOv8  
- Deep Learning  
- Computer Vision
